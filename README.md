# 共生间隙 · Symbiotic Interlude

Web UI 分支的植物互动网站，当前版本 **V4.6**。以黑屏入口、细光尘揭幕和视频转场进入花园，通过植物和空中花笺进行定点探索。包含压力/浇水艺术演示、作品收藏与删除、成长照片、植物心情、纸质日记和钢琴氛围配乐。

## 本地运行

安装 **Node.js 20.11 或更新版本**，在项目根目录运行：

```sh
npm start
```

打开 **http://127.0.0.1:5190**。Windows 也可双击 `start.cmd` 或 `启动共生间隙.cmd`。无需安装第三方运行依赖；保持启动窗口运行，不要直接双击 `index.html`。

更换端口（PowerShell）：

```powershell
$env:PORT='5192'
npm start
```

## 体验流程

1. 点击“轻触，唤醒花园”，观看揭幕；可跳过序幕。
2. 进入花园后，第一次点击植物预览并放大，再次点击进入对应功能。
3. 蝴蝶兰为压力演示，圆叶为浇水演示；点击“一键播放演示”，按住画布拖动留下光迹，随后生成并收藏作品。
4. 下载作品，或点击“放入花笺，返回花园”。向下滚轮/拖动天空，或点击“展开花笺”，访问作品、照片、心情和日记。
5. 相册中的生成作品可删除，需再次确认；删除浇水作品同时移除其虚拟浇水记录。
6. 左下角分别调整音乐、交互音效和环境声。浏览器要求首次点击后才能播放声音。

作品、照片与日记保存在当前浏览器和当前网站地址的 IndexedDB。换端口、换设备或清除网站数据不会自动同步；可在相册导出 JSON 备份。个人运行记录不包含在本仓库中。

## 团队集成状态

当前为完整的前端演示，**尚未连接 TouchDesigner 或实体传感器**。黑色细边框、内部透明的展示位用于后续接入；“一键播放演示”产生网页模拟效果，不是实际传感器数据。浇水次数和植物心情来自虚拟互动记录，不能作为植物健康判断。

网站使用 HTML、CSS、原生 ES Modules、Canvas 2D、WebGL 背景和 Web Audio，暂无后端服务或 AI 图片生成接口。可由任意静态 HTTP 服务托管；上传 GitHub 分支本身不会自动发布为可访问的网站。

目录与后续集成位置见 [团队交接说明](docs/TEAM_HANDOFF.md)。此前的苗绣版本保留在 Git 历史中，本分支根目录现为共生间隙 V4.6。

## 验证

```sh
npm run check
npm test
```

检查包括 JavaScript 语法、引用素材、Windows 启动文件格式，以及植物选择、返回手势、记录校验、心情规则和蝴蝶朝向。性能测试方法与限制见 [V4.5 验收](docs/V4.5性能验收.md)。

## 素材

图片和原视频由项目提供，来源记录见 `assets/metadata.json`。背景柔焦视频由原片预处理得到；配乐和音效为本地合成，钢琴为合成音色。未给用户提供的素材追加开源许可，也不代表这些素材可供他人任意再分发。可直接运行已生成素材；可选配乐重建脚本为 `scripts/compose_music.py`，需要 Python、NumPy 和 FFmpeg。

V4.6：新增入口准备状态、慢加载与失败继续入口、首次两步游园指引及全屏展示。指引可关闭并记住，也可通过右上角帮助按钮重看；全屏时按 Esc 优先退出全屏。
