# 生命绣谱 / LIVING EMBROIDERY

基于 2026-10-24 项目工作手册与《网站制作参考视频》制作的本地演示网站。深色织物、原创花卉绣线主视觉、衬线大标题、缓慢视差与滚动场景过渡；无需安装第三方依赖或联网即可运行。

## 启动

双击 `启动网站.cmd`，保持命令窗口运行，然后访问 **http://127.0.0.1:5186**。需要已安装 Node.js 20 或更新版本。

也可以在本目录运行：

```powershell
$env:PORT='5186'
node scripts/serve.mjs
```

不要直接双击 index.html；ES Modules 需要通过本地 HTTP 服务加载。端口被占用时关闭同一项目的旧服务，或更改 PORT 并访问对应端口。关闭命令窗口或按 Ctrl+C 停止服务。

## 完整体验

1. 首页进入互动创作，点击叶片或“模拟触摸”。针脚密度增加，触摸计数更新。
2. “模拟浇水”增加扩展程度与放射单元，参数变化以 650ms 过渡显示。
3. 切换三种配色、调整参数或生成新构图，点击“完成并保存绣谱”。
4. 保存后选择“试戴我的发饰”，默认使用原创静态人像。调整横纵位置、大小、角度并导出。摄像头只在点击开启后申请权限，失败仍可用静态模式；关闭弹窗或离开试戴会停止视频流。当前为手动定位，无自动人脸追踪。
5. 在“我的绣谱”查看、筛选、更名、再次试戴、导出 1600×1600 PNG 或 1200×1600 海报。删除需再次确认。
6. 苗绣档案提供植物观察、文化学习与原创数字图案。文化详情附中国非物质文化遗产网阅读链接；不会把生成图像标记为传统实物。

作品仅存于当前浏览器、当前网站地址的 localStorage。不同端口、浏览器及设备不共享；清理网站数据会移除作品，请先导出。测试时创建的作品不是预置内容，新浏览器首次打开为空状态。

## 目录

- `src/pages/`：首页、互动创作、档案、作品集。
- `src/styles.css`：基础布局；`src/dark.css`：本次深色视觉与响应式样式。
- `src/lib/`：可重现纹样、存储校验、PNG 与海报导出。
- `src/components/`：导航、动画画布、静态 / 摄像头手动试戴。
- `src/integrations/ports.js`：模拟事件与参数转换边界。
- `assets/`：全部本地视觉素材。
- `docs/`：整合方案、现状、接口、测试记录、素材说明。
- `dist/`：静态交付目录，可放在任意静态 HTTP 服务下运行。

## 验证与构建

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run build
```

自动测试覆盖不同输入映射、参数边界、存储恢复、更名、写入失败及绘图重现。`npm test` 直接执行 Node 测试文件，兼容本机对子进程测试隔离的限制。
