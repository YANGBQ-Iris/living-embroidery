## 运行

安装 Node.js 20.11 或更新版本，在项目目录运行：

```sh
npm start
```

打开 http://127.0.0.1:5190 。Windows 可双击 start.cmd 或 启动共生间隙.cmd；保持启动窗口运行。花园本身无需第三方运行依赖；新增植物抠图需要本机 Python、ONNX Runtime、NumPy、Pillow 及模型，见 [植物上传与 TD](docs/植物上传与TD.md)。不要直接双击 index.html。可通过 PORT 环境变量更换端口。

## 体验

- 每次打开先显示黑屏欢迎页，点击后播放一段 约 10 秒的项目提供开场视频，结束自动进入花园，无第二段视频或二次进入操作；可主动跳过或手动重播。视频缓冲/无法播放时有植物浮现与呼吸光临时画面，可直接进入。
- 轻触植物预览，再次轻触进入。蝴蝶兰为触碰艺术、白花为纹样库、圆叶为浇灌艺术、紫叶为心情。
- 触碰和浇灌页默认接收真实 Arduino 与 TD 画面。连接失败会明确提示，不会自动假装硬件在线。主动切换网页演示后，可用鼠标、触屏、回车/空格与手动强度操作。
- 生成并收藏后，画面定格为实际保存的作品。可下载，或夹进天空花笺，再从相册查看与带走。重新开始可创作新作品。
- 新作品、照片与日记有明确植物归属；可按植物筛选。紫叶入口显示紫叶，心情只统计该植物的互动。旧压力/浇水作品兼容归属，无法判断的旧记录保留为“旧版未分类”。
- 向下滑动空白天空或点“展开花笺”；作品可放大、下载、确认删除。照片和纹样支持本机上传，原有日记保留在纹样库中。
- 右上角查看作品介绍、指引或进入全屏；Esc 关闭弹窗或优先退出全屏。左下角分别调节配乐、环境声与交互声；首次操作后启音。

黑屏首页可按住空白处拖动，以俯视视角短暂展开紫色花朵、放射状绿叶与细草，外围散落碎瓣和微粒，停止后自然淡去。浇灌操作以单滴浅冰蓝水滴回应，与背景光球区分，入土渐隐并产生涟漪。

## 已实现与待接入

已实现网页互动算法、作品导出、植物分类、本机记录、照片/日记、花笺、自然质感音效及钢琴氛围配乐。AI 参与前期视觉、素材与开发辅助；当前运行时没有在线 AI 生成、AI 情绪识别或植物健康诊断。

黑色光影区已支持植物照片上传、本机 AI 抠图、预览确认、TD 自动换图和实际输出回传，使用 GSAP 滚动过渡与网页粒子遮罩。进入花园后向下滚动体验，详见 [植物上传与 TD](docs/植物上传与TD.md)。

蝴蝶兰触碰、圆叶浇灌页已分别连接压力和土壤湿度，显示原有 TD 实际效果；主动切换后仍可使用网页演示。详见 [真实传感器接入](docs/真实传感器接入.md)。内容槽可替换外部视频或可信互动元素，通信、校准和真实输出捕获需团队继续接入。详见 [内容与记录接口](docs/内容与记录接口.md)。

## 记录与素材

IndexedDB 名称保持 symbiotic-interlude-v4，旧记录不删除。记录仅在当前浏览器和网站地址可用，无账号、云存储或跨设备同步。请下载作品或导出 JSON 备份。个人浏览器记录与本机 QA 导出不属于仓库种子数据。

图片与原视频由项目提供，元数据见 assets/metadata.json；柔焦背景为原片派生处理。配乐和多数音效本地合成，钢琴为合成音色；滴水声改用 qubodup 的 CC0 实录并做轻微空间处理，来源见 assets/audio/WATER-SOUND-CREDITS.md。未向用户提供的素材追加开源许可。上传 GitHub 分支不等于自动发布网站。
