# 共生间隙 · Symbiotic Interlude

当前版本 **V4.8**。蓝粉花海中的植物互动艺术网站，保留温柔陪伴、英文标题、白色宋体呼吸光和天空花笺。

## 运行

安装 Node.js 20.11 或更新版本，在项目目录运行：

```sh
npm start
```

打开 http://127.0.0.1:5190 。Windows 可双击 start.cmd 或 启动共生间隙.cmd；保持启动窗口运行。无需安装第三方运行依赖，不要直接双击 index.html。可通过 PORT 环境变量更换端口。

## 体验

- 首次可看一次完整开场，之后直接进入花园；可手动重播。视频缓冲/无法播放时有植物浮现与呼吸光临时画面，可直接进入。
- 轻触植物预览，再次轻触进入。蝴蝶兰为触碰艺术、白花为日记、圆叶为浇灌艺术、紫叶为心情。
- 触碰和浇灌页默认运行可响应的网页演示，可用鼠标、触屏、回车/空格或体验按钮操作。强度滑杆是手动演示控制，不是真实传感器数值。
- 生成并收藏后，画面定格为实际保存的作品。可下载，或夹进天空花笺，再从相册查看与带走。重新开始可创作新作品。
- 新作品、照片与日记有明确植物归属；可按植物筛选。紫叶入口显示紫叶，心情只统计该植物的互动。旧压力/浇水作品兼容归属，无法判断的旧记录保留为“旧版未分类”。
- 向下滑动空白天空或点“展开花笺”；作品可放大、下载、确认删除。照片支持本机上传，日记可填写归属、昵称和观察。
- 右上角查看作品介绍、指引或进入全屏；Esc 关闭弹窗或优先退出全屏。左下角分别调节配乐、环境声与交互声；首次操作后启音。

## 已实现与待接入

已实现网页互动算法、作品导出、植物分类、本机记录、照片/日记、花笺、自然质感音效及钢琴氛围配乐。AI 参与前期视觉、素材与开发辅助；当前运行时没有在线 AI 生成、AI 情绪识别或植物健康诊断。

尚未连接压力/土壤湿度传感器或 TouchDesigner。默认画面明确标为“当前为网页演示”。内容槽可替换外部视频或可信互动元素，通信、校准和真实输出捕获需团队继续接入。详见 [内容与记录接口](docs/内容与记录接口.md)。

## 记录与素材

IndexedDB 名称保持 symbiotic-interlude-v4，旧记录不删除。记录仅在当前浏览器和网站地址可用，无账号、云存储或跨设备同步。请下载作品或导出 JSON 备份。个人浏览器记录与本机 QA 导出不属于仓库种子数据。

图片与原视频由项目提供，元数据见 assets/metadata.json；柔焦背景为原片派生处理。配乐和音效本地合成，钢琴为合成音色。未向用户提供的素材追加开源许可。上传 GitHub 分支不等于自动发布网站。

## 代码与验证

入口 index.html；场景与记录 src/app.js；规则与归属 src/state.js；演示 src/art.js；资源状态 src/presentation.js；作品介绍 src/experience.js；可替换内容 src/content-slot.js；其余 src 文件负责背景、粒子、声音、字效和样式。

```sh
npm run check
npm test
```

以上检查使用 Node 内置功能。完整浏览器验收以 scripts/experience-check.mjs 为当前流程入口，需要开发环境的 Playwright 与 Chrome；此前浏览器脚本保留作历史对照。运行时不依赖这些 QA 工具。完整体验、归属、失败继续与资源清理的验收摘要见 [V4.8 验收](docs/V4.8完整体验验收.md)；本机截图和测试记录不加入团队仓库。
