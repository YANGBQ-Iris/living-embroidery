# 当前网页与 TD

启动网页：运行 D:/web-UI/start.cmd，打开 http://127.0.0.1:5190/ 。

TD 工程：D:/github项目管理/living-embroidery/codex/image_particle_import/pattern_sensors_web.toe。
只打开这一个串口工程；旧 plant-sensors 和单独湿度版应退出，避免抢占 COM15。

- 蝴蝶兰触碰入口：原压力点云聚合画面。压力 AO 接 A1。
- 圆叶浇灌入口：当前敦煌纹样，干燥静止、湿润运动并上下跳跃。土壤 AO 接 A0。
- 两路通过同一个 Arduino COM15/115200 读取，TD 实际渲染画面以约 8fps 回传网页。
- 这是本机现场展示；原公网演示没有自动连接本机硬件。

网页模块文件修改前的备份：.runtime/sensor-input.before-pattern-jump.js。
