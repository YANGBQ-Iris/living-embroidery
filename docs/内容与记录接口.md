# V4.8 内容与记录接口

## 默认体验

压力与浇灌页进入后立即运行 ArtStudy。所有指针、键盘和手动强度均属于网页模拟输入；页面保持“当前为网页演示”。生成成功后定格作品预览，进入收藏/下载阶段；重新开始时创建新的互动会话。

开场仅播放一次原视频，不重复进入同一段视频。资源缓冲时使用 CSS 植物浮现与呼吸光，不依赖原视频解码；媒体错误或无法播放时仍可直接进入花园。每次访问均从黑屏欢迎页开始，点击后播放一段视频，结束自动进入花园；不再按 symbiotic-visited 标记跳过欢迎页。重播按钮可主动再看序幕。

## 替换内容

`src/content-slot.js` 导出 `createContentSlot(host, study, onState)`。当前在 `app.js / renderSensor()` 中创建并保存为 contentSlot。

- `showDemo()`：销毁外部内容，恢复本地网页演示。
- `mountVideo(source)`：接受 http、https 或 blob 地址，播放外部视频。明确标注外部媒体，不声称设备连接成功。
- `mountElement(element, {dispose})`：挂载接入方提供的可信 DOM 元素，如独立 canvas 或播放器。dispose 用于释放该内容拥有的连接与资源。
- `destroy()`：停止外部内容、调用清理回调并销毁演示监听器。离开页面时由应用调用。

以上为前端内容槽，并不包含 TouchDesigner、WebRTC、串口、传感器通信或身份验证实现。团队仍需约定传输方式、单位、校准范围、采样率、断线处理和运行部署条件。

当前“生成并收藏”始终生成网页演示的作品，source 为 demo。未来若要抓取外部内容，需要接入方实现对应的截图/导出方式与来源标记；不能直接将 demo 的结果标为真实传感器输出。跨域视频截图还需要符合媒体来源的跨域策略。

## 植物归属

新作品、日记和照片均保存 plantId，取值 orchid / white / round / violet。姓名、入口和详情图均从同一植物配置获取。心情与统计只使用该植物自己的记录；相册支持按植物筛选。

兼容旧记录：原压力作品可确定归属蝴蝶兰，原浇水作品可确定归属圆叶；无法判断归属的旧日记和照片标记“旧版未分类”，不伪造植物身份。数据库名称和版本不变，不删除旧数据。

## AI 边界

AI 参与前期视觉参考、素材与开发辅助。当前运行时艺术是本地算法绘制，没有在线模型调用、AI 情绪识别或真实植物健康判断。作品介绍已向观众说明已实现与待接入内容。
