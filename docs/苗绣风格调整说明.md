# 苗绣参考纹样视觉调整

基线 arduino 分支提交 214487f，本地修改分支 web-ui-miao-style。仅移植参考图对应的粉青团花、银白旋线与装饰风格。

四株前景植物原图保持一致；Arduino 固件、传感器前端、传感器 API、上传 API、TD 工程与桥接脚本、植物上传逻辑、记录存储和归属规则未修改。

修改 app.js 仅替换花笺空白相框的图片地址；serve.mjs 仅补充 SVG MIME 类型，端口与 API 路由保持原样。其他修改为背景纹理、装饰 CSS、欢迎页及网页演示画布的缓存纹样绘制。真实 TD 输出保持队友提供的原画面。

此版仍按原分支默认等待硬件与 TD，未连接时可以主动切换网页演示进行界面开发。原黑色植物上传区及 GSAP 过渡保留。

纹样依据用户提供参考进行再设计，不附会未经考证的传统寓意。本机使用 PORT=5195 启动以避免与其他预览冲突，仓库默认启动端口未改。
