# 现场运行检查

## 每次启动

1. Arduino 通过 USB 连接本机。压力接 A1、湿度接 A0，保留原接线。
2. 打开 `D:/web-UI/td/plant-sensors.toe`，保持时间轴播放。
3. TD 菜单 Edit → Preferences → General，取消勾选 **Stop Playing when Minimized**，点击 Save。这是本机 TD 首选项，不随 TOE 文件自动迁移；换电脑时也需检查。
4. 运行网站根目录的 `start.cmd`，打开 http://127.0.0.1:5190/ 。
5. 进入蝴蝶兰/圆叶页面，应看到“真实传感器已连接 · TD 实际画面”。可展开“传感器读数”检查原始值。
6. 将 TD 最小化后，网页画面和传感器读数仍应更新。

## 三个入口

- 蝴蝶兰触碰：原点云聚合，轻触约 8 秒，重压约 10 秒；松手等待 2 秒后逐渐散开。
- 圆叶浇灌：原水墨效果随湿度升高显现、下降消退，完整过渡约 6 秒。
- 向下滚动进入黑色照片光影区：上传、抠图、确认换图，与前两路传感器控制分开。取消预览不会改变原植物。

返回花园后应恢复原亮度、按钮与花笺状态，没有黑色展示区或粒子过渡层残留。

## 本机已验证

2026-10-25：真实 Arduino 压力读数 0–1023，湿度原始值 237–1023。已验证植物聚合、松手停留后散开，以及水墨显现后干燥复位。
电脑 1440px 和手机 390px 上，连续切换两轮三个入口、返回、花笺恢复与取消上传通过；没有浏览器运行异常。
本机结果保存在 `output/playwright/complete-flow-results.json` 和 `.runtime/sensor-real-validation.json`。它们是测试记录，不会上传 Git。

## 再次检查

基础检查：`npm run check`、`npm test`。
完整浏览器检查：开发环境提供 Playwright 后运行 `node scripts/integration-check.mjs`。也可设置 `PLAYWRIGHT_MODULE` 为已有 Playwright 包的绝对路径，复用现有工具，无需给网站添加运行依赖。
TD 与本地网站均需启动。完整检查使用独立浏览器，不会删除用户收藏，上传只测试预览取消，不提交替换。
