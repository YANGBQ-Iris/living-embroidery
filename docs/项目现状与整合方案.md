## 视觉转译

1. 深黑靛色织物替代浅纸底，珊瑚、青绿、旧金线色作为强调。
2. 原创绣线花卉及蝶形围合首屏，中央为大宋体标题及斜体英文。
3. 首页由沉浸场景、创作理念、四步体验和结束场景组成；保留随指针缓慢视差与滚动渐显。
4. 创作、档案、作品集采用同一深色体系，纹样使用有序放射、方向性短针脚与重复单元。
5. 手机单列创作区；平板与桌面采用对应网格。尊重系统减少动效设置。
