# 纹样库与湿度入口

白花与天空花笺的日记入口现为纹样库。展示四种参考再设计纹样，可选择预览、上传 PNG JPG WebP（8MB以内）、填写名称、保留透明底并收藏到当前浏览器；刷新后可查看，并可移除自己的上传。最多24张上传，图片边长最多1200像素。

上传图片保存在原 settings 存储中的独立 key living-embroidery-pattern-library-v1。未改变数据库结构、原 records 记录、API或设备数据协议；旧日记保留并在纹样库的“以前的日记”里展开查看。内部 journal 场景标识保留，仅替换其显示内容。

“进入湿度互动”只导航至原有圆叶 moisture 页面，不将上传纹样自动写入 TD、设备或湿度参数，不虚构联动能力。页面继续沿用设备状态和主动切换网页演示方式。

欢迎背景略提亮并增加稀疏花瓣；视频使用轻微亮度调整，粒子在序幕全程可见。原视频素材、黑屏点击、播放结束自动进入花园和跳过流程保持原样。
