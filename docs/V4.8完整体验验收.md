# V4.8 完整体验

保留蓝粉花海、白色宋体呼吸标题、银白蝴蝶和天空花笺。新增/优化：

- 一次开场，无重复视频过渡；再次访问直接进入花园，可手动重播。
- 缓冲与无法播放时有独立的植物浮现/呼吸光画面和真实资源状态，可继续进入；开场黑场揭幕缩短并增加提示。
- 两种互动默认运行，触碰为暖光光迹，浇灌有即时水滴与蓝色涟漪；指针、键盘和按钮均可触发。状态明确为网页演示。
- 生成、收藏、定格预览、花笺定位、相册查看及下载构成连续反馈。生成失败和保存失败保留明确反馈，不伪称成功。
- 入口名称统一为蝴蝶兰、白花、圆叶、紫叶；标签常显、选中高亮。紫叶入口固定先进入紫叶形象，不受旧圆叶记忆影响。
- 新作品、日记和照片有 plantId；各植物统计分别计算，相册可筛选。旧可确定记录兼容归属，不明记录保留为旧版未分类。
- 增大中文功能名、正文与提示，弱化背景、加强前景。手机植物标签不重叠，生成操作与介绍可滚动访问。
- 作品介绍解释项目目的、输入到输出和 AI 实际作用，明确已实现与未来硬件/TouchDesigner 边界。新增可信内容替换槽，未建立真实设备连接。
