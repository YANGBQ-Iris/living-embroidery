# V4.7 水滴、植物与标题

- 浇水演示的水滴到达波纹土壤表面后，按渗入深度平滑降低透明度并略微缩小。吸收完成后完全消失，接触区域短暂扩散涟漪；水滴在土壤上方保持可见。光晕改用缓存图像，减少逐帧径向渐变创建。
- 心情页可在主页同款蝴蝶兰、白花、圆叶和紫叶四种示意图之间切换。预解码图片后再切换，避免空白闪烁；记住选择。此功能切换陪伴植物示意图，现有心情、作品与虚拟浇水记录共用，页面明确标注。
- 花园主标题改为白色宋体字体栈，桌面 1440px 宽时为 44.64px，原为约 28px。使用本机可用的宋体字体，不新增远程字体下载。
- 花园标题及入口、序幕、结尾的主要白色标题，增加 8 秒缓慢呼吸光。底字一直保持不透明；仅 aria-hidden 的装饰柔光层改变透明度，不让正文消失或闪黑。轻量动效与减少动态偏好关闭呼吸动画，隐藏的花园标题暂停动画。
- 修复暂停中的 WebGL 背景在窗口改变尺寸后被清空而显示黑色的问题。尺寸变化后补绘一帧，平时仍保持暂停，不恢复隐藏场景的持续计算。
