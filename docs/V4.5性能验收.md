# V4.5 性能与蝴蝶

蝴蝶绘图的头部是局部 -Y 方向。现在用路径导数得到切线角度，统一旋转身体和翅膀，取消原来的水平镜像，使头部沿实际前进方向飞行；左右两个方向、弯曲和远近缩放均保留。增加细小头部和触角，方便识别朝向。方向测试对不同时间与横竖屏采样，核对头部向量与实际位移向量的夹角。

## 优化

- 植物风感仅在花园与返回过渡期间更新；隐藏相框不更新。相框改用直接 transform，避免每帧修改继承的 CSS 变量，悬停时固定位置便于点击。植物悬停减幅采用阻尼过渡，避免突然跳动。
- 背景织物仅在花园、标题和收尾绘制，约 30Hz；画布按像素预算设置分辨率。粒子与演示按 60Hz 预算采样，在高刷新率显示器上保留余量累积，速度按真实时间计算。
- 交互页仍播放原视频派生的动态背景。新增 ambient.mp4 为原 intro.mp4 的 640×426 / 20fps 预处理柔焦版本，约 0.68MB；不再对原视频每帧叠加全屏实时 backdrop blur。前台只解码需要播放的视频，返回时暂停。
- 缓存花瓣光晕和拖动轨迹彩色光晕，复用轮廓三角函数数据，减少每帧路径点与渐变创建。演示按实际显示尺寸绘制，导出时单次高清重绘，输出仍为 1600×1120。
- 作品 JPEG 改用异步编码，缩短人为等待；植物选择、相框展开、模块进入与返回动画缩短。减轻动态植物的滤镜与大面积重复毛玻璃叠加，保留柔光和半透明质感。

## 测量和验证

测试环境：本机安装的 Chrome，无头模式，1440×900，DPR 1.5，CDP CPU slowdown 4×；每阶段采样 3.5 秒。结果只代表该测试条件，CPU 指标不代表 GPU 时间，也不能保证每台机器达到同样帧率。详见 performance-before.json / performance-after.json。

| 指标 | V4.4 | V4.5 |
| --- | ---: | ---: |
| 花园 P95 帧间隔 | 16.9ms | 16.9ms |
| 花园主线程任务时间 | 1.062s | 1.057s |
| 压力演示 + 拖动光迹 P95 | 16.9ms | 16.8ms |
| 压力演示主线程任务时间 | 2.213s | 1.358s |
| 压力演示脚本时间 | 1.467s | 0.752s |

拖动演示的主线程任务时间减少约 39%，脚本时间减少约 49%；两阶段最终采样均未出现超过 50ms 的帧。花园主线程开销基本相当，风感更新从约 30Hz 提升到随 60Hz 绘制，以改善连续性。

完整流程回归通过 16 项；蝴蝶方向与状态逻辑共 5 项；黑屏与删除通过 12 项。额外反复进入退出传感器页面 4 次，验证隐藏风感/背景停止、柔焦视频播放、原视频暂停、返回后视频暂停，且应用的 pointerup 监听器数量恢复原值。测试工具自身注入的点击监听器不计入应用资源。未发现页面异常。
