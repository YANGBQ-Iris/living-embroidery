# V4.6 展示与引导

- 黑屏入口新增准备状态，植物素材准备完成后恢复安静的声音提示。不显示虚构加载百分比；素材等待超过 7 秒时提示部分仍在准备，并允许继续。
- 视频持续缓冲时延迟显示提示，避免快速加载时闪一下；失败或长时间无法播放时提供“直接进入花园”。进入后过期的播放请求不会让视频在后台继续播放，跳过也不被正在等待的转场锁住。
- 首次进入花园显示两步简短引导：点击植物的两阶段操作、天空花笺入口。可手动关闭，每步 18 秒后自动收起；完成/关闭后记住，不在刷新后重复。右上角“？”可重看。打开花笺或进入模块时收起引导，避免挡住操作。
- 右上角新增浏览器原生全屏展示按钮，状态与浏览器同步。Esc 优先退出全屏，不同时离开植物场景。不支持全屏 API 的环境隐藏该按钮。
- 提示层使用轻量颜色、透明度和位移动画，无新增图片素材、持续计算循环或后台联网服务。
